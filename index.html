ReCovery

by DIMFT

ReCovery by DIMFT is a small, powerful tool for fixing Windows problems after malware infections, built entirely in Python.

Core Capabilities

  • Auto-Admin Elevation: Automatically requests administrator privileges to ensure all system repairs execute successfully.
  • Shell & Registry Repair: Instantly restores corrupted Shell and Userinit registry keys to fix malware that hijacks the Windows startup sequence.
  • Quick WinRE Access: One-click reboot directly into the Windows Recovery Environment for advanced troubleshooting.
  • Built-in Task Manager: A lightweight process viewer that allows you to refresh the active process list and forcefully terminate malicious or frozen applications.
  • System UI Restart: Quickly restart explorer.exe to resolve graphical glitches or taskbar freezes without a full system reboot.
  • Instant CMD Access: Provides immediate, one-click access to the Command Prompt for advanced manual troubleshooting.
